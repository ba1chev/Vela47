# s3_state

The S3 bucket which holds the Terraform state of every other root module of an environment. It is versioned, encrypted, private and reachable only over TLS. Old state versions expire after `noncurrent_version_expiration_days`. Locking uses an S3 lock file (`use_lockfile`), so no DynamoDB table is needed.

`prevent_destroy` protects the bucket. Remove that lifecycle block before you destroy the environment for good.
